# PREEMAX NetMonitor 2.7.33

<!-- PREEMAX:OFFICIAL_TITLE -->
## عنوان رسمی نسخه
`PREEMAX NetMonitor 2.7.33 — Unified DNS & Shecan Control`

<!-- PREEMAX:SUMMARY -->
## خلاصه این به‌روزرسانی
نسخه `2.7.33` تجربه مدیریت سریع DNS و سرویس شکن را تثبیت می‌کند و معرفی قابلیت‌های نسخه را قبل و بعد از Update به‌صورت حرفه‌ای‌تر نمایش می‌دهد.

<!-- PREEMAX:CHANGES -->
## تغییرات مهم
- کارت شناور فشرده برای مدیریت سریع DNS و شکن.
- سوییچ مستقیم و بدون هم‌زمانی بین `D1`، `D2`، `Shecan Free`، `Shecan Pro` و `Automatic / DHCP`.
- حفظ معماری Single-Owner DNS برای جلوگیری از تداخل چند منبع DNS.
- کنترل‌های سریع DNS و پنجره‌های شناور از System Tray.
- Indicator وضعیت DNS روی Tray: سبز برای اتصال سالم، نارنجی برای در حال بررسی/اعمال، قرمز برای خطا و بدون Indicator در حالت Automatic.
- اعلام خودکار Public IP در Shecan Pro پس از تشخیص تغییر IP.
- نمایش عنوان و تغییرات اصلی Release پیش از دانلود و نصب Update.
- نمایش یک‌باره صفحه «چه چیزهایی در این نسخه جدید است؟» در اولین اجرای پس از Update.

<!-- PREEMAX:QUICK_START -->
## شروع سریع
برای مدیریت DNS و شکن، از کارت شناور شکن یا کنترل‌های سریع بالای منوی System Tray استفاده کنید. در هر لحظه فقط یک منبع DNS فعال خواهد بود.
