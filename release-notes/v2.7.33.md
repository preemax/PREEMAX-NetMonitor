# PREEMAX NetMonitor 2.7.33

<!-- PREEMAX:OFFICIAL_TITLE -->
## عنوان رسمی نسخه
`PREEMAX NetMonitor 2.7.33 — Unified DNS & Shecan Control`

<!-- PREEMAX:SUMMARY -->
## خلاصه این به‌روزرسانی
نسخه `2.7.33` مدیریت سریع DNS و سرویس شکن را یکپارچه‌تر می‌کند و دسترسی به گزینه‌های پرکاربرد شبکه را ساده‌تر در اختیار شما قرار می‌دهد.

<!-- PREEMAX:CHANGES -->
## تغییرات مهم
- کارت شناور فشرده برای مدیریت سریع DNS و شکن.
- جابه‌جایی مستقیم بین `D1`، `D2`، `Shecan Free`، `Shecan Pro` و `Automatic / DHCP`.
- فعال بودن فقط یک منبع DNS در هر لحظه برای جلوگیری از تداخل تنظیمات.
- کنترل‌های سریع DNS و پنجره‌های شناور از System Tray.
- نمایش وضعیت DNS روی Tray: سبز برای اتصال سالم، نارنجی هنگام اعمال یا بررسی و قرمز در صورت خطا.
- اعلام خودکار Public IP در Shecan Pro پس از تغییر IP.
- بهبود نمایش اطلاعات نسخه و اصلاح چند مورد گزارش‌شده در بخش به‌روزرسانی.

<!-- PREEMAX:QUICK_START -->
## شروع سریع
برای مدیریت DNS و شکن، کارت شناور شکن یا کنترل‌های سریع بالای منوی System Tray را باز کنید.
