# PREEMAX NetMonitor 1.0.0 RC50

نسخه RC50 زیرساخت به‌روزرسانی داخل برنامه را تکمیل می‌کند.

## تغییرات این نسخه

- بررسی خودکار نسخه جدید هنگام اجرای برنامه، بدون ایجاد وقفه در راه‌اندازی اصلی
- نمایش دکمه آپدیت در هدر فقط زمانی که نسخه جدیدتری در GitHub منتشر شده باشد
- نمایش شماره نسخه جدید مستقیماً در هدر
- بازشدن پنجره اختصاصی به‌روزرسانی از هدر
- شروع خودکار دانلود پس از انتخاب آپدیت از هدر یا صفحه «درباره»
- نمایش درصد دانلود، حجم دریافت‌شده و سرعت دانلود
- اعتبارسنجی SHA-256 فایل Setup پیش از فعال‌شدن نصب
- اضافه‌شدن حالت اختصاصی Installer برای به‌روزرسانی داخل برنامه
- حفظ مسیر نصب، اجزای انتخاب‌شده، تنظیمات و سوابق هنگام Update
- اجرای Setup در حالت Update و راه‌اندازی مجدد PREEMAX NetMonitor پس از نصب
- حفظ رفتار Modify / Reinstall / Uninstall هنگام اجرای دستی Setup
- یکسان‌سازی کامل Version / FileVersion / ReleaseTag روی RC50

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC50_win-x64.exe`
