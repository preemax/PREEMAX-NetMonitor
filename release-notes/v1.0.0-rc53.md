# PREEMAX NetMonitor 1.0.0 RC53

این نسخه مرحله نهایی‌سازی دانلود و اعتبارسنجی فایل نصب را مقاوم‌تر می‌کند.

## تغییرات این نسخه

- محاسبه SHA-256 همزمان با دریافت داده‌ها از GitHub
- حذف نیاز به بازکردن دوباره فایل دانلودشده بلافاصله پس از رسیدن دانلود به 100٪
- کاهش احتمال تداخل Windows Defender یا آنتی‌ویروس در مرحله اعتبارسنجی
- مقاوم‌سازی بررسی فایل‌های کش‌شده در برابر قفل موقت فایل
- حفظ Retry کنترل‌شده برای نهایی‌سازی فایل Setup
- اضافه‌شدن لاگ داخلی تشخیصی Updater بدون نمایش Exception خام به کاربر
- مسیر لاگ تشخیصی: `%LOCALAPPDATA%\PREEMAX\NetMonitor\Logs\update-errors.log`
- یکسان‌سازی Version / FileVersion / ReleaseTag روی RC53

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC53_win-x64.exe`
