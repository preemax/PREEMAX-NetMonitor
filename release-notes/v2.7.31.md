# PREEMAX NetMonitor 2.7.31

## خلاصه این به‌روزرسانی

نسخه `2.7.31` تمرکز ویژه‌ای روی **مدیریت سریع DNS و سرویس شکن** دارد. در این نسخه کاربر می‌تواند بدون باز کردن صفحه تنظیمات، از طریق کارت شناور و System Tray بین DNSهای تعریف‌شده، شکن رایگان، شکن حرفه‌ای و حالت Automatic جابه‌جا شود.

## قابلیت‌های جدید و بهبودها

- اضافه شدن **کارت شناور فشرده شکن** برای کنترل سریع وضعیت و DNS.
- امکان سوییچ مستقیم بین:
  - `D1`
  - `D2`
  - `Shecan Free`
  - `Shecan Pro`
  - `Automatic / DHCP`
- حفظ قانون **Single-Owner DNS**؛ در هر لحظه فقط یک منبع DNS فعال است و از هم‌زمانی یا تداخل بین DNS Profiles و شکن جلوگیری می‌شود.
- اگر برای D1 یا D2 مقداری تعریف نشده باشد، گزینه مربوطه غیرفعال است و Tooltip اعلام می‌کند که مقداری تنظیم نشده است.
- اضافه شدن **اعلام خودکار IP در حالت Shecan Pro** پس از تغییر Public IP؛ پس از تشخیص تغییر، برنامه حدود 10 ثانیه صبر می‌کند و سپس IP جدید را یک بار اعلام می‌کند.
- بهبود System Tray با **Indicator اختصاصی وضعیت DNS**:
  - سبز چشمک‌زن: DNS فعال و پاسخ‌گو
  - نارنجی چشمک‌زن: در حال اعمال یا بررسی
  - قرمز: خطا یا عدم پاسخ
  - بدون Indicator: حالت Automatic / DHCP یا نبود DNS فعال
- بزرگ‌تر شدن Indicator وضعیت DNS برای خوانایی بهتر.
- اضافه شدن **کنترل‌های سریع در بالای منوی System Tray** برای:
  - نمایش/مخفی‌کردن Mini Watch
  - نمایش/مخفی‌کردن کارت شناور شکن
  - روشن/خاموش‌کردن سریع DNS
- اضافه شدن Chip وضعیت رنگی کنار کنترل‌های سریع Tray.
- توسعه Tooltip آیکن System Tray برای نمایش اطلاعات بیشتر درباره `NET`، `VPN`، DNS فعال و Public IP.
- بازطراحی منوی Tray با ساختار حداکثر دو سطحی برای جلوگیری از روی‌هم‌افتادن زیرمنوها در کنار لبه صفحه.

## رفتار DNS سریع

در صورت خاموش کردن DNS از Tray، تنظیمات به `Automatic / DHCP` برمی‌گردد. هنگام روشن کردن مجدد، آخرین منبع DNS استفاده‌شده در صورت موجود بودن دوباره فعال می‌شود.

## Shecan

- Shecan Core: `1.2.0`
- پشتیبانی از DNS رایگان و حرفه‌ای شکن
- پشتیبانی از اعلام IP برای سرویس حرفه‌ای
- Backup/Restore تنظیم DNS قبلی در چارچوب مالکیت واحد DNS

## Windows

- Platform: Windows 10 / Windows 11
- Architecture: x64
- Version: `2.7.31`
- Installer: `PREEMAX_NetMonitor_Setup_2.7.31_win-x64.exe`

## پیش از به‌روزرسانی

اگر از نسخه قدیمی‌تر استفاده می‌کنید، پس از نصب نسخه جدید تنظیمات DNS Profiles و تنظیمات شکن را یک بار بررسی کنید. در حالت عادی برنامه تنظیمات قبلی را حفظ می‌کند.

## پس از نصب

برای استفاده سریع، از System Tray یا کارت شناور شکن استفاده کنید. تنها یک DNS در هر لحظه فعال خواهد بود و بازگشت به Automatic نیز از همان کنترل‌های سریع در دسترس است.
