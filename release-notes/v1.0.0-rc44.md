# PREEMAX NetMonitor 1.0.0 RC44

اولین نسخه عمومی آزمایشی PREEMAX NetMonitor برای Windows 10/11 x64.

## Highlights

- پایش وضعیت Offline / Local Network / Intranet / Global Internet
- پایش Public IP با منطق پایدارتر برای جلوگیری از اعلان‌های کاذب
- تشخیص Wi‑Fi / Ethernet / USB Tethering / Bluetooth
- پایش VPN و تفکیک مصرف با VPN / بدون VPN
- تاریخچه مصرف داده و گزارش‌های مقایسه‌ای
- گزارش مصرف اینترنت برنامه‌ها
- Network Scan و Wi‑Fi Scan
- DNS Profiles و Quick Switch
- Website & Service Monitoring
- Dashboard، Mini Watch و System Tray
- Installer استاندارد Windows با Minimal / Typical / Full / Custom
- Modify / Reinstall / Uninstall و ثبت در Windows Installed Apps

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC44_win-x64.exe`
- Portable package: در صورت انتشار همراه همین Release ارائه می‌شود.
