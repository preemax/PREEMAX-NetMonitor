# PREEMAX NetMonitor 1.0.0 RC52

نسخه RC52 خطای نهایی‌سازی دانلود در مسیر به‌روزرسانی داخل برنامه را رفع می‌کند.

## تغییرات این نسخه

- رفع خطایی که باعث می‌شد دانلود تا 100٪ کامل شود اما مرحله اعتبارسنجی/نهایی‌سازی شکست بخورد
- بستن کامل فایل موقت دانلود پیش از اجرای SHA-256
- حفظ اعتبارسنجی SHA-256 منتشرشده در GitHub
- افزودن Retry برای زمانی که Windows یا آنتی‌ویروس فایل دانلودشده را موقتاً قفل می‌کند
- نمایش پیام دقیق‌تر در صورت خطای نهایی‌سازی فایل
- افزایش نسخه به RC52 / FileVersion 1.0.0.52

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC52_win-x64.exe`
