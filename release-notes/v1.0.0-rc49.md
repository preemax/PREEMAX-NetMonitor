# PREEMAX NetMonitor 1.0.0 RC49

نسخه آزمایشی جدید PREEMAX NetMonitor برای Windows 10/11 x64.

## Highlights

- بررسی به‌روزرسانی از GitHub Releases
- پنجره اختصاصی دانلود و نصب به‌روزرسانی داخل برنامه
- نمایش نسخه فعلی و نسخه جدید
- نمایش درصد دانلود، حجم دانلودشده و سرعت
- اعتبارسنجی SHA-256 فایل Setup پیش از نصب
- اجرای Installer استاندارد PREEMAX پس از دانلود
- بهبود پایداری ساخت Installer در برابر قفل موقت فایل توسط Windows Defender / آنتی‌ویروس
- حفظ همه قابلیت‌های پایش شبکه، گزارش مصرف، VPN، Wi-Fi، DNS، Website Monitor و Mini Watch

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC49_win-x64.exe`

فایل‌های `SHA256SUMS.txt` و `RELEASE_MANIFEST.json` همراه Release منتشر شوند.
