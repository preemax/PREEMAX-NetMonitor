# PREEMAX NetMonitor 1.0.0 RC45

نسخه آزمایشی جدید PREEMAX NetMonitor برای Windows 10/11 x64 با قابلیت بررسی مستقیم به‌روزرسانی از GitHub Releases.

## تغییرات اصلی

- فعال شدن دکمه «بررسی به‌روزرسانی» در پنجره درباره برنامه
- بررسی مستقیم Releaseهای رسمی مخزن PREEMAX-NetMonitor
- تشخیص نسخه جدیدتر، آخرین نسخه و Build جدیدتر از Release عمومی
- پشتیبانی از کانال Release Candidate و Stable
- هدایت کاربر به فایل Setup رسمی سازگار با معماری Windows
- حفظ تمام قابلیت‌های RC44 شامل پایش شبکه، VPN، مصرف، گزارش‌ها، اسکن شبکه و Installer استاندارد

## Windows

- Platform: Windows 10/11
- Architecture: x64
- Installer: `PREEMAX_NetMonitor_Setup_1.0.0-RC45_win-x64.exe`

PREEMAX / ماناکاوش
