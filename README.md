هدف برنامه فقط نمایش سرعت لحظه‌ای نیست؛ NetMonitor برای **ثبت تاریخچه، تفکیک مصرف، مقایسه اتصال‌ها، تشخیص تغییرات، هشدار و گزارش‌گیری در طول زمان** طراحی شده است.

# تصاویر واقعی برنامه

> تصاویر زیر از خود PREEMAX NetMonitor گرفته شده‌اند. Taskbar ویندوز از تصاویر حذف شده است. در صفحه «مقایسه اتصال»، دو تصویر اسکرول‌شده از همان صفحه برای نمایش کامل‌تر محتوا به هم متصل شده‌اند. محتوای اصلی رابط کاربری با تصویر تولیدی جایگزین نشده است.

## مصرف اینترنت و تفکیک مسیر اتصال

<p align="center">
  <img src="docs/screenshots/01-usage-overview.webp" alt="PREEMAX NetMonitor - Internet usage overview" width="100%" />
</p>

این بخش برای ثبت و بررسی حجم اینترنت مصرف‌شده طراحی شده است. Download، Upload و مجموع مصرف در بازه‌های زمانی مختلف قابل مشاهده هستند و مصرف را می‌توان بر اساس وضعیت **VPN روشن/خاموش**، نوع اتصال و پایه یا منبع اتصال بررسی کرد.

NetMonitor اتصال‌هایی مثل `Wi-Fi`، `Ethernet`، اینترنت موبایل از طریق `USB Tethering` و سایر واسط‌های شبکه را از هم تفکیک می‌کند. در Wi-Fi نیز SSID مبنای مهمی برای تشخیص منبع اتصال است و اطلاعات فنی شبکه مانند Band و Channel در بخش‌های مرتبط استفاده می‌شوند.

گزارش‌ها برای بازه‌هایی مانند امروز، هفته، ماه، 7D، 30D، 90D، 12M و بازه سفارشی در نظر گرفته شده‌اند و خروجی CSV نیز در بخش‌های گزارش وجود دارد.

NetMonitor مصرف شبکه برنامه‌ها و Processها را ثبت می‌کند تا مشخص شود هر برنامه چه مقدار اینترنت استفاده کرده است.

برای هر برنامه می‌توان اطلاعاتی مانند Download، Upload، مجموع مصرف، مصرف از طریق VPN، مصرف بدون VPN، نوع اتصال، پایه اتصال و آخرین فعالیت ثبت‌شده را بررسی کرد. بنابراین فقط مشخص نمی‌شود «کدام برنامه اینترنت مصرف کرده»، بلکه می‌توان دید آن مصرف از چه اتصال و با چه وضعیت VPN انجام شده است.

ثبت مصرف برنامه‌ها در پس‌زمینه مستقل از باز بودن صفحه گزارش ادامه پیدا می‌کند. هنگام ورود به صفحه گزارش یک بار بارگذاری انجام می‌شود و پس از آن تازه‌سازی می‌تواند دستی یا بر اساس فاصله زمانی انتخابی کاربر انجام شود.

</p>

NetMonitor امکان تعریف **دو مسیر DNS** را فراهم می‌کند. هر پروفایل می‌تواند DNS اصلی و جایگزین خود را داشته باشد و کاربر بتواند بین آن‌ها سریع جابه‌جا شود.

تغییر DNS از طریق Mini Watch برای استفاده روزمره سریع طراحی شده است؛ D1 و D2 مستقیماً در دسترس هستند تا بدون ورود به تنظیمات اصلی بتوان پروفایل DNS را تغییر داد. برای هر پروفایل امکان تعریف Hotkey نیز در نظر گرفته شده است تا تغییر DNS با میانبر صفحه‌کلید انجام شود.

این قابلیت برای کاربرانی که از سرویس‌های DNS مختلف استفاده می‌کنند یا لازم است بین دو مسیر DNS جابه‌جا شوند، یکی از ابزارهای اصلی Mini Watch است.

# قابلیت‌های اصلی

## 1. ثبت و محاسبه مصرف اینترنت با تفکیک واقعی مسیر اتصال

یکی از بخش‌های اصلی NetMonitor، ثبت Download و Upload در طول زمان است. برنامه فقط یک عدد کلی از مصرف اینترنت نشان نمی‌دهد و داده‌ها را با چند مبنا قابل تفکیک نگه می‌دارد:

- Download و Upload
- مجموع مصرف
- مصرف با **VPN روشن**
- مصرف با **VPN خاموش / اتصال مستقیم**
- نوع اتصال `Wi-Fi / Ethernet / USB Tethering / Bluetooth`
- پایه یا منبع اتصال
- SSIDهای مختلف Wi-Fi
- بازه‌های روزانه، هفتگی، ماهانه و سفارشی

این ساختار کمک می‌کند مشخص شود چه مقدار از حجم اینترنت روی یک اتصال مشخص مصرف شده، چه مقدار هنگام استفاده از VPN بوده و چه مقدار از مسیر مستقیم عبور کرده است.

## 2. آمار روزانه، هفتگی، ماهانه و تاریخی

NetMonitor تاریخچه مصرف را نگهداری می‌کند تا کاربر فقط وضعیت همین لحظه را نبیند. گزارش‌ها برای بررسی امروز، هفته جاری، ماه جاری، 7D، 30D، 90D، 12M و بازه سفارشی طراحی شده‌اند.

در گزارش مصرف می‌توان Download، Upload و مجموع مصرف را بر اساس مسیر اتصال، نوع اتصال و وضعیت VPN فیلتر یا مقایسه کرد.

## 3. تشخیص مصرف VPN و اتصال مستقیم

در گزارش مصرف می‌توان مشاهده کرد:

- چه مقدار داده با VPN منتقل شده است
- چه مقدار بدون VPN منتقل شده است
- سهم VPN از مصرف کل
- هر برنامه چه مقدار از VPN استفاده کرده است
- مصرف هر Connection Source در حالت VPN یا Direct

منطق تشخیص VPN فقط به نام ساده یک Adapter محدود نیست و مسیر، PPP/Tunnel و آداپتورهای رایج VPN نیز در تشخیص وضعیت استفاده می‌شوند.

## 4. رصد زنده Public IP و Location

NetMonitor تغییرات Public IP و Location تقریبی اتصال را رصد می‌کند. تغییر IP یا کشور/Location می‌تواند به‌عنوان Event ثبت شود و بر اساس تنظیمات کاربر هشدار ایجاد کند.

این قابلیت در زمان اتصال یا قطع VPN، تغییر سرور VPN، تغییر ISP، تغییر Public IP توسط اپراتور یا جابه‌جایی بین Wi-Fi، Ethernet و اینترنت موبایل کاربرد دارد.

Mini Watch نیز برای نمایش سریع IP، کشور/پرچم، وضعیت شبکه و VPN طراحی شده است.

## 5. تشخیص Internet Global / Local / Offline

برنامه تلاش می‌کند فقط به عبارت Connected ویندوز متکی نباشد و وضعیت واقعی دسترسی را در چند سطح تشخیص دهد:

- نبود اتصال فعال
- شبکه محلی بدون اینترنت
- Intranet / دسترسی داخلی
- Global Internet

تغییر وضعیت اینترنت ملی/داخلی و اینترنت جهانی می‌تواند در قالب Event و اعلان قابل شخصی‌سازی به کاربر نمایش داده شود.

## 6. گزارش کیفیت اینترنت و مقایسه ISPها

شاخص‌های کیفیت مانند Ping، Jitter، Packet Loss، DNS Response و Availability در طول زمان ثبت می‌شوند. وقتی کاربر از چند منبع اینترنت استفاده می‌کند، سابقه آن‌ها جدا نگه داشته می‌شود تا کیفیت مسیرها و ISPهای مختلف در بازه‌های هفتگی و ماهانه قابل مقایسه باشد.

## 7. هشدارهای سرعت و مصرف Download / Upload

سیستم Alert فقط برای قطع اینترنت نیست. کاربر می‌تواند رخدادهای مهم را رصد کند و برای شرایط موردنظر اعلان دریافت کند؛ از جمله عبور سرعت Download یا Upload از حد تعریف‌شده یا رسیدن مصرف به آستانه موردنظر.

اعلان‌ها قابل شخصی‌سازی هستند و حالت صوتی و بصری برای سناریوهای مختلف شبکه در نظر گرفته شده است.

## 8. مصرف اینترنت هر برنامه

برای هر برنامه یا Process، Download، Upload، مجموع مصرف، سهم VPN/Direct، نوع اتصال و پایه اتصال قابل ثبت و گزارش است. این بخش کمک می‌کند مشخص شود کدام برنامه در چه زمانی و از کدام اتصال بیشترین مصرف را داشته است.

## 9. Website & Service Monitoring

بخش مانیتور سایت‌ها مستقل از پنجره اصلی طراحی شده و می‌تواند در پس‌زمینه ادامه کار دهد. URL، Interval، Timeout، Failure Threshold، Slow Response Threshold و Expected Status Code برای Targetها قابل تعریف هستند و Uptime، Response Time، Failure و رخدادهای سرویس ثبت می‌شوند.

## 10. DNS Profiles و Quick Switch

دو DNS Profile قابل تعریف هستند. تغییر بین پروفایل‌ها می‌تواند از Mini Watch و با یک کلیک انجام شود و Hotkey مستقل برای هر پروفایل نیز قابل تنظیم است.

## 11. Network Scan و Wi-Fi Scan

NetMonitor ابزارهای مستقلی برای بررسی شبکه متصل و شبکه‌های Wi-Fi اطراف دارد.

در Network Scan اطلاعاتی مانند IP، MAC، Hostname، Vendor، زمان مشاهده و اطلاعات سرویس/پورت‌های شناسایی‌شده نمایش داده می‌شوند.

در Wi-Fi Scan نیز اطلاعاتی مانند SSID، BSSID، Channel، Band، RSSI و Security قابل بررسی هستند.

## 12. Mini Watch و System Tray

Mini Watch برای مشاهده دائمی اطلاعات مهم بدون باز نگه داشتن پنجره اصلی طراحی شده است. اطلاعاتی مثل Public IP، کشور، VPN، سرعت، مصرف و DNS می‌توانند در آن نمایش داده شوند.

برنامه با System Tray نیز کار می‌کند تا مانیتورینگ و سرویس‌های پس‌زمینه بعد از بسته شدن پنجره اصلی متوقف نشوند.
